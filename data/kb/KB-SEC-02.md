---
id: KB-SEC-02
title: Workspace security settings
tags: security, it
---

Enterprise admins can restrict access to IP ranges (CIDR) in Settings > Security > Network, enforce two-factor authentication for all members, and review the audit log.
Real-time updates use websockets: corporate proxies and firewalls must allow websocket connections to *.fluxo.example.
Suspected security incidents (unknown logins, leaked tokens, data exposure) are escalated to the Fluxo security team, who answer within 4 hours; revoke exposed tokens immediately in Settings > API.
